# 調査・実装候補の記録

この `triage` ブランチは、調査結果・判断根拠・実装候補を継続して保存するためのものです。PRやmainへのマージを目的にしません。

## 参照方法

- 実装候補を選ぶ前に、この一覧と該当する調査記録を読む。
- 記録の日付と調査時のmainを確認し、Issue・既存PR・コードの現在の状態を再確認する。
- 実装は最新のmainから別ブランチを作って進める。`triage` を実装ブランチの親にしない。
- 実装・マージされた候補は、関連PRと検証結果を記録に追記する。
- 観測した事実、Issueでの報告、提案、未検証事項を区別する。
- 過去の判断を消して書き換えるより、日付を付けて更新理由を残す。

作業コピーを切り替えずに読む例:

```text
jj file show -r triage triage/README.md
jj file show -r triage triage/2026-10-29-frontend-modernization.md
```
